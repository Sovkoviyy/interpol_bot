# 🦅 INTERPOL BOT • Majestic RP Family Bot & Web Dashboard

Многофункциональный Discord-бот и веб-панель управления для семьи на сервере Majestic RP.
Включает в себя: систему заявок с тикетами, умные сборы на мероприятия (дропы, цеха, ВЗМ, капты) с резервом и авто-удалением сообщений через 30 минут, базу участников с инвайтами, полный аудит сервера по 8 каналам (включая лог ивентов) и авто-возврат ролей при повторном входе.

---

## ⚡ Быстрый запуск в 3 шага

### Шаг 1. Создайте бота в Discord
1. Зайдите в [Discord Developer Portal](https://discord.com/developers/applications) ➔ **New Application**.
2. Вкладка **Bot**:
   * Нажмите **Reset Token** и скопируйте токен.
   * **ОБЯЗАТЕЛЬНО** включите 3 галочки в блоке **Privileged Gateway Intents**:
     * ✅ Presence Intent
     * ✅ Server Members Intent
     * ✅ Message Content Intent
3. Вкладка **OAuth2 ➔ General**:
   * Скопируйте **Client ID** и **Client Secret**.
   * В поле **Redirects** добавьте: `http://localhost:3001/api/auth/callback`
4. Вкладка **OAuth2 ➔ URL Generator**:
   * Отметьте `bot` и `applications.commands`.
   * Права: `Administrator` (или права на управление каналами и ролями).
   * Скопируйте ссылку внизу и пригласите бота на ваш Discord-сервер.

---

### Шаг 2. Настройка файла `.env`
Скопируйте файл `.env.example` и переименуйте в `.env` (или отредактируйте существующий `.env`):
```env
DISCORD_TOKEN=ваш_токен_бота
CLIENT_ID=ваш_client_id
CLIENT_SECRET=ваш_client_secret
GUILD_ID=id_вашего_discord_сервера
```
*(Все остальные настройки уже заполнены по умолчанию).*

---

### Шаг 3. Запуск

Все компоненты (база данных SQLite, фронтенд React, бэкенд TypeScript) **собираются и запускаются автоматически из одного файла**:

#### 💻 На Windows:
* Просто дважды кликните по файлу **`start.bat`** (или выполните в терминале `npm start`).
* Веб-панель откроется по адресу: **http://localhost:3001**

#### 🐧 На Linux (Ubuntu VPS):
```bash
# 1. Установите зависимости (один раз)
npm install

# 2. Запустите единый скрипт
chmod +x start.sh
./start.sh
```
*Для непрерывной работы 24/7 в фоне через PM2:*
```bash
# Сборка проекта
npm run build

# Запуск в PM2
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

### 🛡️ Настройка OpenResty / Nginx / aaPanel (Reverse Proxy)

Если сайт открывается через OpenResty или Nginx (например, в **aaPanel**):

#### 1. Конфигурация виртуального хоста (Reverse Proxy)
Убедитесь, что в конфигурации сайта (вкладка **Reverse Proxy** в aaPanel или конфиг Nginx) указан порт `3001`:
```nginx
location / {
    proxy_pass http://127.0.0.1:3001;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_connect_timeout 60s;
    proxy_read_timeout 60s;
    proxy_send_timeout 60s;
}
```

#### 2. Если вы видите ошибку `502 Bad Gateway (openresty)`:
1. **Проверьте статус процесса бота в PM2:**
   ```bash
   pm2 status
   pm2 logs interpol_bot --lines 50
   ```
2. **Проверьте, занят ли порт 3001:**
   ```bash
   lsof -i :3001
   # или освободите зависший старый процесс:
   fuser -k 3001/tcp
   pm2 restart interpol_bot
   ```
3. **Проверьте доступность локального сервера:**
   ```bash
   curl -I http://127.0.0.1:3001/api/health
   ```
   Должен возвращаться статус `HTTP/1.1 200 OK`.

## 🎮 Основные команды Discord

| Команда | Описание |
| :--- | :--- |
| `/recruit post` | Опубликовать красивое объявление с кнопкой «Подать заявку» |
| `/recruit config` | Быстрая привязка роли рекрутеров, роли семьи и категорий |
| `/event create` | Создать сбор на МП (выбор дня Сегодня/Завтра, авто-подстановка запомненного войса и роли) |
| `/logs setup` | За 1 секунду создать категорию `LOGS` и все 8 каналов аудита (включая `#ивенты-лог`) |

## 🌐 Возможности веб-панели (Dashboard)

Вход в панель осуществляется через Discord (или через кнопку **Dev-вход** для быстрого доступа):
* **Обзор (Dashboard):** Мониторинг онлайна, активные сборы, заявки и переключатели модулей.
* **Участники (Members):** Полный каталог участников сервера с поиском по нику/ID, фильтрами по ролям, статусом в войсе и отслеживанием использованных инвайт-ссылок.
* **Сборы на МП (Events):** Создание сборов с быстрым выбором даты («Сегодня», «Завтра», «Послезавтра»), авто-расчетом чек-ина, запоминанием каналов публикации и войса, а также **автоматическим удалением сообщений сбора через 30 минут** после окончания.
* **Заявки в семью (Recruitment):** Просмотр анкет, конструктор вопросов (до 5 полей), управление тикетами.
* **Аудит сервера (Logs):** Наглядные Switch-тумблеры включения/выключения для 8 категорий (сообщения, участники, роли, каналы, голос, инвайты, бот и **ивенты**) с авто-созданием каналов в 1 клик.
* **Уровни доступа (RBAC):** Матрица прав для ролей Discord.
* **Статистика (Stats):** Детальная аналитика явки на МП, эффективности рекрутеров и активности состава.
