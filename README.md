# 🦅 INTERPOL BOT • Majestic RP Family Bot & Web Dashboard

Многофункциональный Discord-бот и веб-панель управления для семьи на сервере Majestic RP.
Включает в себя: систему заявок с тикетами, умные сборы на мероприятия (дропы, цеха, ВЗМ, капты) с резервом, полный аудит сервера по 7 каналам и авто-возврат ролей участникам при повторном входе.

---

## ⚡ Быстрый запуск в 3 шага

### Шаг 1. Создайте бота в Discord
1. Зайдите в [Discord Developer Portal](https://discord.com/developers/applications) ➔ **New Application**.
2. Вкладка **Bot**:
   * Нажмите **Reset Token** и скопируйте токен.
   * **ОБЯЗАТЕЛЬНО** включите 3 галочки в блоке **Privileged Gateway Intents**:
     * ✅ Presence Intent
     * ✅ Server Members Intent
     * ✅ Message Content Intent
3. Вкладка **OAuth2 ➔ General**:
   * Скопируйте **Client ID** и **Client Secret**.
   * В поле **Redirects** добавьте: `http://localhost:3001/api/auth/callback`
4. Вкладка **OAuth2 ➔ URL Generator**:
   * Отметьте `bot` и `applications.commands`.
   * Права: `Administrator` (или права на управление каналами и ролями).
   * Скопируйте ссылку внизу и пригласите бота на ваш Discord-сервер.

---

### Шаг 2. Настройка файла `.env`
Скопируйте файл `.env.example` и переименуйте в `.env`:
```env
DISCORD_TOKEN=ваш_токен_бота
CLIENT_ID=ваш_client_id
CLIENT_SECRET=ваш_client_secret
GUILD_ID=id_вашего_discord_сервера
```
*(Все остальные настройки уже заполнены по умолчанию).*

---

### Шаг 3. Запуск

Все компоненты (база данных, фронтенд, бэкенд) **собираются и запускаются автоматически из одного файла**:

#### 💻 На Windows:
* Просто дважды кликните по файлу **`start.bat`** (или выполните команду `npm start`).
* Веб-панель откроется по адресу: **http://localhost:3001**

#### 🐧 На Linux (Ubuntu VPS):
```bash
# 1. Установите зависимости (один раз)
npm install

# 2. Запустите единый скрипт
chmod +x start.sh
./start.sh
```
*Или для работы 24/7 в фоне через PM2:*
```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```

## 🧪 Тестовый режим с Cloudflare Tunnel (Windows)
Если вы хотите сначала протестировать бота на локальном ПК, не трогая основную базу, и открыть веб-панель через интернет:
1. Запустите **`start_test_environment.bat`**.
2. Скрипт сам запросит токен и ID сервера, создаст отдельную базу `test_env/test.db` и поднимет бесплатный домен Cloudflare вида:
   ```text
   https://xxxx.trycloudflare.com
   ```
   По этой ссылке веб-панель будет доступна с любого устройства (компьютера, телефона).

## 🎮 Основные команды Discord

| Команда | Описание |
| :--- | :--- |
| `/recruit post` | Опубликовать красивое объявление с кнопкой «Подать заявку» |
| `/recruit config` | Быстрая привязка роли рекрутеров, роли семьи и категорий |
| `/event create` | Создать сбор на мероприятие (дроп, цех, ВЗМ, капт) |
| `/logs setup` | За 1 секунду создать категорию `LOGS` и все 7 каналов аудита |

## 🌐 Возможности веб-панели (Dashboard)

Вход в панель осуществляется через Discord (или через кнопку **Dev-вход** для локального теста):
* **Обзор (Dashboard):** Мониторинг онлайна, активные сборы, заявки и тумблеры быстрого включения/выключения модулей.
* **Заявки в семью:** Просмотр анкет кандидатов, конструктор вопросов формы (до 5 полей) и привязка каналов.
* **Сборы на МП:** Запуск сборов прямо из браузера, управление составом участников и автоматический резерв.
* **Аудит сервера:** Выбор каналов для логирования 7 категорий (сообщения, участники, роли, каналы, войс, инвайты, бот).
* **Права и доступ (RBAC):** Матрица прав для ролей Discord (Лидер, Заместители, Рекрутеры, Офицеры).
* **Статистика:** Лидерборд и эффективность рекрутеров семьи (количество закрытых заявок, процент одобрения).
