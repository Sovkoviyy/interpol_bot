# INTERPOL BOT • Majestic RP Family Management System

Модульный Discord-бот и веб-панель управления (Admin Dashboard) для семьи на сервере Majestic RP.

---

## 🚀 Основные возможности

### 1. Модуль рекрутинга / заявок в семью
* **Интерактивная кнопка подачи:** Бот публикует аккуратный Embed с кнопкой `Подать заявку`.
* **Модальное окно:** Пользователь заполняет форму (до 5 вопросов: Имя/Фамилия, Статик, Возраст, Опыт, Онлайн). Все вопросы и подсказки настраиваются через веб-панель!
* **Приватный канал-тикет:** Автоматически создается канал `заявка-{ник}` в указанной категории с доступом только кандидату и рекрутерам.
* **Управление статусом заявки:**
  * 📌 `Взять на рассмотрение` — закрепляет заявку за рекрутером.
  * ✅ `Одобрить` — автоматически выдает роль семьи, формирует полный текстовый транскрипт в лог-канал, уведомляет в ЛС и удаляет тикет.
  * ❌ `Отклонить` — открывает модальное окно для ввода причины отказа, отправляет причину в ЛС кандидату, кикает с сервера, отправляет транскрипт в лог-канал и удаляет тикет.

### 2. Модуль сборов на мероприятия (МП)
* **Два типа мероприятий:**
  1. **Без лимита участников** (Дропы, цеха, массовые сборы).
  2. **С ограничением состава** (ВЗМ, МЦЛ, капты) с автоматической системой **Резерва (Waitlist)**.
* **Умные прогрессивные напоминания:** Бот автоматически пингует целевую роль или состав с уменьшающимся интервалом до проверки явки (чек-ина) и начала (например: за 15, 10, 5, 3, 1 мин).
* **Интерактивный состав в реальном времени:**
  * Кнопки `Записаться`, `В резерв`, `Отказаться`.
  * При отказе человека из основы бот **автоматически переводит первого кандидата из резерва в основной состав** и присылает ему уведомление!
  * Организатор или офицер может исключать участников прямо из меню управления.
* **Привязка голосового канала:** Указание существующего войса для сбора состава.

### 3. Модуль полного аудита и логирования сервера
* Логирует **абсолютно все события** сервера с точным определением исполнителя (через Audit Logs) и раскладкой по отдельным каналам в категории `LOGS`:
  * `#сообщения-лог` (удаление, редактирование, массовая очистка сообщений).
  * `#участники-лог` (вход, выход, кик, бан, разбан, смена ника, смена аватара, тайм-ауты).
  * `#роли-лог` (создание, удаление, редактирование прав, выдача/снятие роли с участника).
  * `#каналы-лог` (создание, удаление, переименование).
  * `#войс-лог` (вход, выход, переходы между войсами, серверный мут).
  * `#инвайты-лог` (создание, удаление инвайтов).
  * `#бот-лог` (действия рекрутеров, одобрения заявок, запуск сборов).
* **1-Click Auto Setup:** Кнопка в веб-панели или слэш-команда `/logs setup` сама за 1 секунду создает категорию `LOGS` и все 7 каналов с правильными правами доступа!

### 4. Веб-панель управления (Admin Dashboard)
* Авторизация через **Discord OAuth2** (плюс Dev-вход для локального тестирования без интернета).
* **Гибкая ролевая модель доступа (RBAC):** Назначение прав на отдельные модули сайта (Лидер, Зам, Рекрутер, Офицер МП).
* **Конструктор формы заявки:** Редактирование вопросов, стилей полей и плейсхолдеров в браузере.
* **Запуск и мониторинг сборов:** Создание сборов прямо из браузера с публикацией в Discord.
* **Статистика и лидерборд:** Рейтинг активности рекрутеров (сколько заявок закрыто, процент одобрения).

## 🛠️ Стек технологий
* **Бэкенд & Бот:** Node.js v24, TypeScript, `discord.js` v14, Express.js.
* **База данных:** SQLite (локально / прод) с Prisma ORM. При необходимости мгновенно переключается на PostgreSQL.
* **Веб-интерфейс:** React 18, Vite, Tailwind CSS, Lucide Icons, Axios.

## ⚙️ Настройка и запуск

### 1. Создание приложения в Discord Developer Portal
1. Перейдите в [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, назовите бота (например, `Interpol Family Bot`).
3. В разделе **Bot**:
   * Нажмите **Reset Token** и скопируйте токен бота (`DISCORD_TOKEN`).
   * Включите все три **Privileged Gateway Intents**:
     * ✅ **Presence Intent**
     * ✅ **Server Members Intent** (Обязательно для заявок, ролей и логирования)
     * ✅ **Message Content Intent** (Обязательно для логирования сообщений)
4. В разделе **OAuth2 -> General**:
   * Скопируйте **Client ID** (`CLIENT_ID`).
   * Скопируйте **Client Secret** (`CLIENT_SECRET`).
   * В **Redirects** добавьте: `http://localhost:3001/api/auth/callback` (для продакшна укажите ваш домен/IP: `https://your-domain.com/api/auth/callback`).
5. Пригласите бота на сервер через **OAuth2 -> URL Generator**:
   * Scopes: `bot`, `applications.commands`.
   * Permissions: `Administrator` (рекомендуется для полного управления каналами и ролями).

### 2. Заполнение файла `.env`
Скопируйте `.env.example` в `.env` и заполните:
```env
DISCORD_TOKEN=ваш_токен_бота
CLIENT_ID=ваш_client_id
CLIENT_SECRET=ваш_client_secret
GUILD_ID=id_вашего_discord_сервера

PORT=3001
JWT_SECRET=любая_длинная_случайная_строка
FRONTEND_URL=http://localhost:5173
DISCORD_REDIRECT_URI=http://localhost:3001/api/auth/callback

DATABASE_URL="file:./dev.db"
```

## 🧪 Изолированное тестовое окружение (Sandbox)

Для безопасного тестирования создана отдельная папка `test_env/`, которая гарантирует, что ваши тесты не повлияют на основную рабочую базу данных и настройки:
* Собственная тестовая база данных: `test_env/test.db`
* Собственный файл конфигурации: `test_env/.env`
* Запуск с автоматическим туннелем Cloudflare

### Быстрый запуск тестового окружения в 1 клик:
Запустите файл **`start_test_environment.bat`** (в корне проекта или `test_env/start_test.bat`).

При первом запуске скрипт интерактивно запросит:
1. `DISCORD_TOKEN` тестового бота
2. `CLIENT_ID` приложения
3. `CLIENT_SECRET` приложения
4. `GUILD_ID` тестового сервера
5. Порт (по умолчанию: `3001`)

Скрипт автоматически сохранит их в `test_env/.env`, инициализирует тестовую базу данных, запустит бота в изолированном окне и выдаст публичную ссылку Cloudflare вида `https://xxxx.trycloudflare.com`!

## 💻 Локальный запуск (Windows / Тест)

1. **Инициализация базы данных:**
```bash
npm run prisma:push
```

2. **Запуск бэкенда и бота:**
```bash
npm run dev
```

3. **Запуск веб-панели (в отдельном терминале):**
```bash
cd web
npm run dev
```
Панель откроется по адресу: `http://localhost:5173`

## 🌐 Развертывание на Ubuntu 24.04 VPS (Production)

### 1. Установка Node.js (v20 или v22):
```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs git
sudo npm install -g pm2
```

### 2. Клонирование и установка:
```bash
git clone <url-вашего-репозитория> interpol_bot
cd interpol_bot

# Установка зависимостей бэкенда
npm install

# Установка зависимостей фронтенда
cd web
npm install
npm run build
cd ..

# Применение схемы БД
npm run prisma:push

# Сборка TypeScript бэкенда
npm run build
```

### 3. Запуск через PM2:
```bash
pm2 start ecosystem.config.js
pm2 save
pm2 startup
```
Бот и веб-сервер будут работать в фоне 24/7 с автоматическим перезапуском при сбоях и перезагрузке сервера!

## 🎮 Слэш-команды в Discord
* `/recruit post` — Опубликовать сообщение с кнопкой «Подать заявку».
* `/recruit config` — Быстрая настройка роли рекрутеров, роли семьи и категорий.
* `/event create` — Объявить сбор на мероприятие (дроп, цех, ВЗМ и др.).
* `/logs setup` — Автоматически создать категорию `LOGS` и 7 каналов аудита.
